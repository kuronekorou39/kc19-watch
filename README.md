# 空室監視 Bot（Telegram通知 + Webダッシュボード + 予約アシスト）

予約サイトの空室状況を定期的にチェックし、空きが出たら Telegram に通知するツールです。
全部屋・全プランを自動で走査して推移を記録し、通知は欲しい部屋だけに絞れます。
空室検知時に予約フォームを途中まで自動入力して人に渡す（handoff）機能もあります。

> 対象サイト・施設・プランなどの実値はリポジトリに含めません。
> **共有設定ファイル（`settings.share.yaml`）** として別途配布し、アプリに読み込ませます。

## 使い方（exe版・Python不要）

1. Releases から `kc19-watch.zip` をダウンロードして展開する
2. 共有された `settings.share.yaml` を **kc19-watch.exe と同じフォルダ** に置く
3. exe をダブルクリック → ブラウザに画面が開く
   （SmartScreen の警告が出たら「詳細情報」→「実行」）
4. **設定タブ**：チェックリストが全部 ✓ か確認。通知が欲しい場合は
   [@BotFather](https://t.me/BotFather) で自分用 Bot を作りトークンを貼って
   「保存して接続」→ Telegram で自分の Bot に `/start`
5. **走査タブ**：「▶ 走査開始」を押す

## ソース版（uv）

```bash
uv sync
uv run kemocon   # Webダッシュボード + Bot → http://127.0.0.1:8000
```

## 配る側

```powershell
./build_exe.ps1   # => dist/kc19-watch.zip
```

Releases には zip だけを上げ、`settings.share.yaml` は LINE 等で別途共有します。

## 注意

- 予約はキャンセル規定付きの本予約です。既定では最終確定は人間が押します
  （設定で最終確定まで自動にもできますが、本予約が確定します）。自己責任でご利用ください。
- 各サイトの利用規約に従い、過度なアクセス（短すぎる間隔）は避けてください。
- Bot（トークン）は各自専用に作成してください。`/start` した人は誰でも通知先に登録されます。
